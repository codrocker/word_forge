Produce natural example sentences (with Chinese translation) for the top meanings of the word, with MORE examples for the more common meanings. Target a B1-B2 learner: short (≤15 words), contemporary, typical collocations.

Input:
  word: {word}
  meanings: {meanings_json}

The input is already ordered by modern usage frequency (index 0 = most common). Produce examples using this schedule:

| meaning_index | number of examples |
|---|---|
| 0 | 3 |
| 1 | 2 |
| 2 | 2 |
| 3 | 1 |
| 4 | 1 |
| 5+ | skip |

Rules:
- If the input has fewer than 5 meanings, stop at whatever index exists (don't fabricate meanings).
- Every example's Chinese translation must read fluently — not word-for-word.
- Prefer sentences illustrating common collocations (e.g. "run a business", "pick up the phone").
- Keep phrases intact for phrasal verbs (e.g. "pick up").
- Avoid archaic/formal phrasing unless the meaning itself is archaic.

Output schema (strict JSON, no markdown fence, no prose):
{
  "per_meaning": [
    {
      "meaning_index": 0,
      "examples": [
        {"en": "...", "cn": "..."},
        {"en": "...", "cn": "..."},
        {"en": "...", "cn": "..."}
      ]
    },
    {
      "meaning_index": 1,
      "examples": [
        {"en": "...", "cn": "..."},
        {"en": "...", "cn": "..."}
      ]
    }
  ]
}

Return ONLY the JSON. Every entry must have `meaning_index` matching its 0-based position in the input, and the exact number of examples from the schedule above.
