Given an English word and its meanings, produce:
  1. Morphological word-forms (if applicable): plural, past_tense, past_participle, third_person, present_participle, comparative, superlative. Only include fields that actually exist for this word — e.g. adjectives don't have `past_tense`; irregular verbs need the real irregular form, not the regularized one.
  2. Per-meaning semantic derivatives: synonyms (2-5) and antonyms (0-3). Pick items that a learner would actually encounter, not obscure thesaurus options.

Input:
  word: {word}
  meanings: {meanings_json}

Output schema (strict JSON, no markdown fence, no prose):
{
  "word_forms": {
    "plural": "optional",
    "past_tense": "optional",
    "past_participle": "optional",
    "third_person": "optional",
    "present_participle": "optional",
    "comparative": "optional",
    "superlative": "optional"
  },
  "per_meaning": [
    {
      "meaning_index": 0,
      "synonyms": ["..."],
      "antonyms": ["..."],
      "equivalents": ["optional — near-synonyms that cover the same sense"]
    }
  ]
}

Omit `word_forms` entries that don't apply (e.g. return `{}` for adjectives lacking past_tense). `meaning_index` must match input meanings[i] positions. Return ONLY the JSON.
