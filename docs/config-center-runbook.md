# LLM 配置中心 — 运营同学操作说明

> 入口：web admin → 顶部「配置中心」。三类对象都带版本：**每次保存生成新版本，
> 历史永不丢失，可一键回退**。密钥只写不读：保存后任何页面都看不到明文，仅显示尾 4 位。

## 1. 供应商配置（endpoint + 密钥）

1. 「供应商配置」Tab → 填名称（如 `deepseek-official`）、Base URL（如
   `https://api.deepseek.com/v1`）、sk 密钥 → 保存。
2. 点「拉取模型列表」验证密钥可用——能拉到模型名即配置成功。
3. 改 Base URL / 换密钥：点「编辑」→ 填新值 → 保存为新版本。**留空的密钥不会变**；
   换密钥只更新当前生效值，不产生版本历史（密钥永不进版本）。
4. 出问题想回退：版本条上点「回退到 v N」（只回退非密钥字段）。

## 2. 提示词库

1. 「提示词库」Tab → 名称 + 模板内容 → 保存。模板里可用变量槽：
   `{word}`（单词）、`{dict_summary}`（词典摘要）。
2. 修改提示词 = 保存为新版本；旧版本可回退。
3. 提示词质量建议先用小批量实验验证（见下），避免直接大规模使用。

## 3. Agents（版本化组合）

1. 「Agents」Tab → 名称 + 选供应商配置 + 模型名（可从供应商的模型列表复制）+
   选提示词 → 保存。
2. Agent 会**固定创建当时各组件的版本**（如 供应商 v1 + 提示词 v2），
   之后组件升级不影响已有 Agent——要吃新版需编辑 Agent 生成新版本。
3. 回车快速换模型名也会生成新版本。

## 4. 跑实验（对比效果与成本）

1. 「LLM 实验」页 → 顶部选 Agent → 填词数（质量对比建议 50）和种子。
2. **同种子 = 同一批词**：不同 Agent 用同一种子跑，结果可直接对比
   （有效数 / 成本 / 每词输出一目了然）。
3. 每次运行都记录了所用组件的精确版本快照（agent/供应商/提示词的版本与内容哈希），
   事后可审计任何一次结果是谁产出的。
4. 不选 Agent 则走「点选模式」（服务器环境变量配置的供应商）。

## 安全约定

- 密钥加密存储（服务端 `WORDFORGE_CONFIG_SECRET` 环境变量提供加密密钥）。
- 密钥只在保存时经手一次：不进版本历史、不进日志、不回显到任何页面。
- Base URL 不允许 localhost / 内网地址。

## 面向部署者（一次性）

- 部署 web 服务的环境需设置 `WORDFORGE_CONFIG_SECRET`（生成方式：
  `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`，
  存入部署的 env 文件；**丢失该密钥 = 已存的供应商密钥全部失效需重录**）。
- 数据库迁移：`uv run alembic upgrade head`（0013 新增配置中心表）。
